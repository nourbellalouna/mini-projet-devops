# Gestion des incidents informatiques

## Présentation

Cette application web permet à un établissement d'enseignement supérieur de gérer les incidents informatiques signalés par les étudiants et les enseignants.

## Technologies utilisées

- Python
- Flask
- SQLite
- HTML
- CSS
- Pytest
- Docker
- Docker Compose
- GitHub Actions

## Fonctionnalités

- Ajouter un incident.
- Afficher la liste des incidents.
- Consulter les détails d'un incident.
- Modifier le statut d'un incident.
- Supprimer un incident.

## Informations d'un incident

- Identifiant
- Titre
- Description
- Lieu
- Priorité : Faible, Moyenne ou Élevée
- Statut : Nouveau, En cours ou Résolu
